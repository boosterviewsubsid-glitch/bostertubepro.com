1. Pendahuluan

BosterTubePro (bostertubepro.com) adalah tools analisis YouTube untuk membantu creator menganalisis channel kompetitor, mengoptimalkan judul, deskripsi dan hashtag dengan skor SEO & estimasi RPM, serta mengunggah dan menjadwalkan video ke channel mereka sendiri.

Kebijakan ini menjelaskan data apa yang kami akses, bagaimana kami menggunakannya, menyimpannya, dan melindunginya ketika Anda menghubungkan akun Google / YouTube ke BosterTubePro.

2. Data yang Kami Akses (via Google OAuth & YouTube Data API v3)

Data berikut hanya diakses setelah Anda memberi izin di layar persetujuan resmi Google:

  • Akun Google: email, nama dan ID profil — untuk login dan mengenali akun Anda.
  • Data channel: ID channel, nama, thumbnail, jumlah subscriber, total views dan jumlah video — untuk menampilkan channel Anda di dashboard.
  • Data video: daftar video beserta judul, deskripsi, tag, thumbnail, durasi, status privasi, tanggal publikasi dan statistik publik — untuk audit video dan saran SEO.
  • YouTube Analytics: views, watch time, geografi penonton, dan estimasi pendapatan (hanya jika channel sudah monetisasi dan Anda memberi izin data pendapatan) — untuk laporan analytics di dashboard.

Tindakan pada channel Anda — hanya saat Anda memintanya. Dengan izin Anda, BosterTubePro dapat mengunggah video dan Shorts, memasang thumbnail, mengubah judul / deskripsi / tag, menjadwalkan publikasi, dan memasang label “altered or synthetic content” (konten AI) sesuai kebijakan YouTube. Kami tidak pernah menghapus video, menulis komentar, atau mengubah channel Anda tanpa tindakan langsung dari Anda di aplikasi.

  • Kami TIDAK pernah meminta atau menyimpan password Google / YouTube Anda. Login sepenuhnya lewat Google OAuth 2.0 resmi.
  • Kami tidak mengakses Gmail, kontak, Google Drive, atau data pembayaran Google Anda.

3. Penggunaan Google User Data

  • Data YouTube hanya digunakan untuk menjalankan fitur yang Anda pakai di aplikasi: menampilkan analytics di dashboard, audit video, saran judul / deskripsi / hashtag, upload dan penjadwalan video.
  • Kami TIDAK menjual, menyewakan, atau membagikan data Anda ke pihak ketiga untuk kepentingan mereka.
  • Kami TIDAK menggunakan data Anda untuk iklan, profil iklan, atau melatih model AI umum.
  • Google Ads API: data kata kunci (volume pencarian dan CPC) diambil dari akun Google Ads Keyword Planner milik BosterTubePro sendiri, hanya untuk menampilkan estimasi RPM hashtag. Kami tidak mengakses atau mengelola akun Google Ads Anda.
  • Pemrosesan AI: saat Anda memakai fitur AI (misalnya analisis video saat upload, Tiru Judul, atau audit), teks yang relevan — dan untuk analisis upload, beberapa frame gambar serta audio dari video yang Anda pilih — dikirim ke Google Gemini hanya untuk menghasilkan judul, deskripsi dan hashtag. Data ini tidak kami simpan setelah hasilnya dikirim kembali ke Anda.
  • Penyedia infrastruktur yang menjalankan aplikasi atas nama kami (hosting, database, AI) hanya memproses data sebatas yang diperlukan untuk fitur tersebut, atau bila diwajibkan hukum.

4. YouTube API Services

Aplikasi ini menggunakan YouTube API Services. Dengan menggunakan BosterTubePro, Anda menyetujui YouTube Terms of Service, dan data Anda di Google diatur oleh Google Privacy Policy.

5. Penyimpanan & Keamanan

  • Token OAuth: refresh token disimpan terenkripsi (AES-256-GCM) di database server kami, agar channel tetap terhubung dan upload terjadwal tetap bisa dipublikasikan saat Anda offline. Access token berumur pendek (±1 jam) disimpan di server dan di browser Anda selama sesi, lalu kedaluwarsa otomatis. Token tidak pernah ditampilkan ke pengguna lain.
  • Data akun: saldo Poin, riwayat transaksi Poin, data channel yang terhubung, jadwal upload, hasil audit, dan riwayat generate disimpan di database kami.
  • Cache API: data channel dan video dari YouTube API disimpan sementara (sekitar 24 jam) untuk menghemat kuota, dan hanya ditampilkan ke akun Google pemiliknya.
  • File video: kami tidak menyimpan file video asli Anda. Saat upload, file dikirim langsung dari browser Anda ke YouTube. Jika Anda memilih “Tidak - Upload Video Asli”, video diunggah apa adanya tanpa dibuat ulang dengan AI.
  • Semua data dikirim lewat koneksi HTTPS terenkripsi. Tidak ada metode yang 100% aman, tetapi kami menerapkan pengamanan yang wajar untuk melindungi data Anda.

6. Pencabutan Akses & Penghapusan Data

  • Cabut akses: buka myaccount.google.com/permissions, pilih BosterTubePro, lalu klik Hapus akses. BosterTubePro langsung tidak bisa lagi mengakses data YouTube Anda.
  • Hapus data: hubungi boosterviewsubsid@gmail.com untuk penghapusan data, dari email yang terhubung dengan akun Anda, dengan subjek HAPUS DATA SAYA. Kami akan menghapus data akun, token yang tersimpan dan cache data YouTube Anda, lalu mengirim konfirmasi.
  • Data di browser: Anda bisa menghapus data lokal dengan logout atau membersihkan penyimpanan browser.

7. Privasi Anak

BosterTubePro tidak ditujukan untuk anak di bawah 13 tahun (atau usia minimum di negara Anda). Kami tidak dengan sengaja mengumpulkan data anak. Jika Anda yakin seorang anak memberikan data kepada kami, hubungi kami dan data tersebut akan dihapus.
